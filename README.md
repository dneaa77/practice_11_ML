## Тема: Влияние PCA на качество модели и время обучения

**Вариант:** B

### 1. Цель работы

Исследовать влияние метода главных компонент (PCA) на качество классификации, время обучения и количество используемых признаков.

### 2. Датасет

Использован Breast Cancer Wisconsin (Diagnostic) из библиотеки scikit-learn.

- Количество наблюдений: 569.
- Количество признаков: 30.
- Количество классов: 2.
- Тип задачи: бинарная классификация.

### 3. Использованные методы

- StandardScaler — масштабирование признаков.
- LogisticRegression — модель классификации.
- PCA — уменьшение размерности.
- Pipeline — объединение этапов обработки и обучения.
- StratifiedKFold — кросс-валидация на 5 разбиениях.
- Accuracy — метрика качества.

### 4. Эксперименты

Обучена базовая модель без PCA.

Дополнительно обучены модели с сохранением 80%, 90% и 95% дисперсии.

Для каждой модели измерены точность классификации, время обучения и количество компонент.

Результаты экспериментов сохранены в файле `results/comparison.csv`.
